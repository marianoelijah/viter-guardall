# Guard-All Electronic Security Systems - Full Stack Web Application

A professional web application ecosystem built for Guard-All Electronic Security System Inc. to showcase world-class electronic security products, client partnerships, and integrated solutions.

🌐 **Live Demo:** [https://viter-guardall.vercel.app](https://viter-guardall.vercel.app)

---

## 🚀 Features
* **Dynamic Content Delivery:** Pulls interactive content directly from a managed cloud database.
* **Component Architecture:** Built with modern, modular frontend views using React and Tailwind CSS.
* **Decoupled API Integration:** Communicates over a secure REST API architecture linking frontend client pages to backend controllers.

---

## 🛠️ Technology Stack

### Frontend
* **React 19** & **Vite** - High-performance user interface rendering
* **Tailwind CSS** - Modern, utility-first application styling
* **Framer Motion** - Fluid animations and interactive banner transitions

### Backend & Database
* **Node.js** & **Express.js** - Robust REST API layer
* **MySQL2** - High-performance database client queries
* **Aiven Cloud** - Managed MySQL cloud database infrastructure

### Deployment & Hosting
* **Vercel** - Optimized global CDN hosting for frontend deployment
* **Render** - Dynamic cloud service application container for backend API hosting
